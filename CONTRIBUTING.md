# Contributing

This repository is public for portfolio and review purposes but remains
proprietary. A pull request does not grant permission to reuse or deploy the
project.

Before proposing a change:

1. Open an issue describing the problem and intended scope.
2. Do not include real guest data, credentials, database exports, internal
   runbooks, or production infrastructure details.
3. Keep public, staff, import-service, and Stripe-webhook trust boundaries
   explicit.
4. Run the checks documented in the root README.
5. Keep changes focused; unrelated refactors may be rejected.

Use private vulnerability reporting for security issues rather than issues or
pull requests.
